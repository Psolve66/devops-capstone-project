# Account Microservice with CI/CD and Kubernetes Deployment

```
This project focuses on designing and enhancing a customer account microservice for an e-commerce platform using a RESTful architecture built with Flask. The service manages customer data by implementing full CRUD functionality—create, read, update, delete, and list accounts—while leveraging an existing database model and partially completed API. Development follows agile practices, including user stories, backlog refinement, sprint planning, and iterative implementation.

In addition to feature development, the project emphasizes DevOps best practices. It incorporates continuous integration with linting and unit testing, security enhancements such as CORS and headers, containerization using Docker, and deployment to Kubernetes. A complete CI/CD pipeline automates testing, building, and deployment, ensuring reliable delivery of the microservice in a cloud-native environment.

```
